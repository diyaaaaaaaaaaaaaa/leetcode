##  First Approach

### Idea
two pointers

### Algo
1. 2 ptrs- one for haystack, one for needle
2. the only catch was to keep another pts for the starting position
3. after every mismatch, increment the starting position by 1
4. return j= needle.size() ? j : -1;
        MISTAKE-- missed the edge case where only half of the chars of needle would match and haystck would be over. hence only returning j if its size is the same as needle.

## ⏱ Complexity

| Time | Space |
|------|-------|
| `O(n)` | `O(1)` |

---

##  2nd Approach

### Key IDea
haystack.substr(pos, len);

### Algorithm

1. iterate from 0 to haystack.size()-needle.size()
2. check if haystack.substr(i,needle.size()) is same as needle, 
          = if yes, return i
          = if no, return -1


---

## ⏱ Complexity

| Time | Space |
|------|-------|
| `O(nm)` | `O(1)` |

n= haystack.size()
m= needle.size(), comes for substr func

---

##  Takeaways

- substr func creates a substring temporarily which take O(m) space
