# 2095. Delete the Middle Node of a Linked List
> **Difficulty:**   easy
> **Topics:** linked lists
> **Link:**https://leetcode.com/problems/delete-the-middle-node-of-a-linked-list/

---

##  Approach

### Key Insight

traverse the whole list once to get the number of nodes
go to the middle
change links

### Algorithm

1. maintain a variable cnt that counts the number of nodes traversed.
2. traverse the full list to get cnt
3. if cnt is 1, return null
4. go the node just before the middle one, calling it mover
5. change mover's next node to be middle's next one
6. change middle's next node to be null
7. return head

### Why it works

we're changing the nodes that the pointers point towards.

##  Takeaways

- do NOT break existing links before establishing new ones.
