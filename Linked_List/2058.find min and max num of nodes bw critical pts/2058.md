# 2058. Find the Minimum and Maximum Number of Nodes Between Critical Points
> **Difficulty:**   easy
> **Topics:** linked list

---

##  Approach

### Algorithm

1. initialise a vector criticalpts and an int pos to store the critical points we find and their positions.
2. if num of nodes in the ll is less that 4, 2 critical points would not be possible and ans will be {-1,-1}.
2. initialise a node prev that points to head of the ll and a node temp which will point to the node next to head.
3. loop till the second last node of ll and 
        - compare the values of nodes prev, temp and temp->next.
        - if a critical point is found, push its position to criticalpts.
        - after each iter, inc pos by 1.
4. if less than 2 critical points are found, ans will be {-1,-1}.
5. maximum distance will be the difference between the last and first elements of criticalpts.
6. loop though criticalpts, and calculate the difference between each node and campare them to find the minimum difference.
7.  return {minDistance, maxDistance};
