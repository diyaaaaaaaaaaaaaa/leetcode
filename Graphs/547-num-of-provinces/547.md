# 547. Number of Provinces
> **Difficulty:**   mid
> **Topics:** graphs
> **Pattern:** connected components
> **Link:**https://leetcode.com/problems/number-of-provinces/description/

---

##  Approach

### Key Insight
multiple bfs

### Algorithm

1. the isConnected matrix is our adjancy matrix, convert it to adj list.
     - traverse the matrix looking for ones.
     - if found, adj[i].push_back(j);
2. intialise the empty queue and vis arr
3. traverse the vis arr and every time a not visited element is found, run bfs/dfs
4. count the number of times bfs is run and return it.


---

## ⏱ Complexity

| Time | Space |
|------|-------|
| `O(n^2)` | `O(n^2)` |

---

##  Takeaways

- use vector<vector<int>> adj(n+1) instead of vector<int> adj[n+1]
- if each node is connected to every other and there are n nodes, the adjacency list can contain O(n²) entries.
- u could traverse the matrix directly to reduce sapce.
