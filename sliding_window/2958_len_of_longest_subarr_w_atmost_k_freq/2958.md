# 2958. Length of Longest Subarray With at Most K Frequency

> **Pattern:** sw, hashing

## Brute force

### Key Insight
SW+hashing

### Algorithm

1. Initialize maxSize = 0.
2. For every possible starting index start:
    - Create an empty frequency map.
    - Set end = start.
3. Expand the subarray from start toward the right:
    - Increment the frequency of nums[end].
    - If the frequency of nums[end] becomes greater than k, stop expanding this subarray.
    - Otherwise, calculate the current subarray size as end - start + 1.
    - Update maxSize if this size is larger.
    - Move end to the next position.
4. After trying every possible start, return maxSize.
---

## ⏱ Complexity

| Time | Space |
|------|-------|
| `O(n^2)` | `O(n)` |

---
##  Optimised Approach

### Key Insight
sw

### Algorithm

1. initialise an unordered map
2. set start ptr=0
3. for the sw, loop from end ptr=0
         - increment the freq of element that end points to
         - while freq of end elem exceeds k,
                  - decrement the freq of start elem
                  - inc start ptr by 1
        - calculate size of the window

### Why it works
brute force was O(n^2) and we were recomputing the frequencies in every iteration, using sw, we just add or remove from the frequencies.
