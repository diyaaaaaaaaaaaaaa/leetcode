# 4089. Count Subarrays With Loose Bounds

> **Difficulty:**   easy
> **Link:**https://leetcode.com/problems/count-subarrays-with-loose-bounds/description/

---

##  Approach

### Algorithm

1. keep two variables ans, which will be our final ans and run, which counts the number of elements in current subarray.
2. loop through the array, for each valid element inc run
3. if an invalid element is encountered, add sum of all the elements from 0 to run to ans and reset run to 0.
4. after the loop, add sum from 0 to run to ans again to include the last valid sub array(s) of the input array.
5. return ans

### Why it works

if the total valid elemnts in a subarray is 4, there can be 1+2+3+4 possible smaller sub arrays within it.
