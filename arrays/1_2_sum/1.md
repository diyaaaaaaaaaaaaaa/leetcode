# 1. Two Sum 
> **Difficulty:** easy
> **Topics:** arrays, hashing
> **Pattern:** hashmap
> **Link:**https://leetcode.com/problems/two-sum/description/

---

##  Approach

### Key Insight
only put it in the map if its been seen and not used

### Algorithm
1. initialise a hash map
2. for each int in nums
   - calculate target-nums[i] ie the next int thats needed aka comp
   - search for comp in the hash map
           - if found, output is i and index of comp in nums
           - if not found, add comp and its index to the hash map
