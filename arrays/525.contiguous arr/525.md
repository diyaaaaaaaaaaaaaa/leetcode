##  Approach

### Algorithm

1. initialise an unordered map pref and two variable sum, which stores the prefix sum and ans, which will hold the max valid length.
2. for the map pref, keys are the prefix sum of each id and values are th ecorresponding ids. initialise pref[0]=-1
3. traverse throuhg the arr and add -1 to the total sum for each 0 encountered and 1 for each 1 encountered.
4. if for an id, the sum has been seen before (tracked by the map), the diference between the current id and the id for which the same sum has been seen will be the lenght of a valid id.
5. else add the current sum to the map.
6. for eahc valid length found, compare it to the value held by the ans variable and keep updating.

### Why it works

if prefix sums for two ids are the same it means, the elements between the two ids have a sum of 0 that is equal number of 0s and 1s.
