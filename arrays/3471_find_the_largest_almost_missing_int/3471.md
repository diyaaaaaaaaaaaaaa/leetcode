##  Approach

### Algorithm

1. Initialise an unordered map for storing frequencies of elements of nums.
2. loop though nums and count the frequency of each element.
3. if k=1, each subarr will have only one element
     - the greatest unique element will be our ans
4. if n>k>1, only the two extreme elements (pos wise) can be our answers if duplicates do not exist. The middle elements will show up in atleast 2 subarr.
    - if nums[0] has a duplicate, nums[n-1] will be our ans and vice versa.
    - if both nums[0] and nums[n-1] have duplicates, ans would be -1.
    - if neither have a duplicate, ans will be the greater one of nums[0] and nums[n-1].
5. if n=k, only one subarr would exist. the greates element would be our answer. Here, the duplicates do not matter, since the question only requires the ans to apprear in one subarr.
