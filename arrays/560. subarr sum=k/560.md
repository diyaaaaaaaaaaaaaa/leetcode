# 560. Subarray Sum Equals K
> **Difficulty:**   hard
> **Pattern:**  prefix sum
> **Link:**https://leetcode.com/problems/subarray-sum-equals-k/description/

---

##  Approach

### Key Insight

if total sum is s, and at some point sum was s-k, there will be a sub array with sum k

### Algorithm

1. keep variables sum which keeps the prefix sums and ans which keeps the count of required s-k
2. initialise an unordered map and add value 1 to key 0. keys are the prefix sums and values are their frequencies.
3. loop through the array and calculate the prefix sum for each element
4. if in the map, prefix sum - target exists as a key, add its freq to ans
5. inc freq of current prefix sum in the map
6. return ans

### Why it works

storing prefix sums is easier
